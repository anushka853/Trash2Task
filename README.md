# 🏆 Trash2Task AI — 

Overview

CivicPulse AI is an AI-powered smart civic issue reporting platform that enables citizens to report public problems such as garbage accumulation, potholes, broken streetlights, and waterlogging. The platform connects citizens, municipal authorities, and field workers through a single workflow for faster issue resolution.

Features

- AI-assisted issue reporting from uploaded images
- Automatic issue categorization
- Admin dashboard for monitoring complaints
- Worker task assignment and status updates
- Live issue tracking
- Citizen leaderboard and reward system
- Interactive map for viewing reported issues
- Analytics dashboard for monitoring city performance
